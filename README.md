A two-line robot confession: one sentence owning a specific mistake, one naming the lesson and the fix. I set your alarm for seven in the evening instead of seven in the morning — now I read the time back before I save it.

`main.py` writes the apology to `/output/entry.txt` (UTF-8, mode 0644), validating it is 1–400 characters, exactly two non-empty lines, each one sentence, with no control characters first.

Built with [make.fun](https://make.fun/?ref=wa8qfxzr).
